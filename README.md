# Mis tareas sobreviven

Laboratorio guiado de iOS con SwiftUI y SwiftData: guarda tareas y filtra la lista por estado. El proyecto inicial compila y deja pequeños fragmentos de código para que los completes.

## Empieza aquí

1. Obtén la rama **`lab-swiftdata-filtros`** y crea tu rama de trabajo siguiendo [la preparación del laboratorio](SEGUNDA_SESION.md).
2. Abre [`codelab/swiftdata-filtros.html`](codelab/swiftdata-filtros.html) desde Finder: es una guía en español disponible offline.
3. Abre **`TODOiOSLab.xcodeproj`** en Xcode 27.1 y selecciona un iPhone Simulator instalado o tu iPhone ya preparado.
4. Sigue los ejercicios y verifica cada resultado.
5. Guarda al menos dos commits propios y entrega un PR nuevo desde `lab/swiftdata-tu-alias` hacia **main de tu fork**, con las capturas solicitadas.

## Requisitos

Mac con Xcode 27.1 y un simulador iOS compatible previamente instalado, o un iPhone preparado. El deployment target es iOS 17. SwiftData ya está configurado y activo. La app utiliza un almacenamiento independiente de la práctica inicial.

Git, un clon de tu fork y acceso a GitHub. Si cambiaste de Mac, configura tu identidad local de Git. El token temporal anterior puede haber vencido.

No hay dependencias externas ni herramientas adicionales que instalar. La guía y la app funcionan offline; obtener ramas, hacer push y abrir un PR requieren conexión.

Si GitHub muestra una plantilla de PR anterior, reemplázala con `.github/pull_request_template.md` de tu rama actual, como explica la guía.
